# Bnw-colors theme

A mixed VS Code theme: **dark interface, light code**.

The editor stays light so your code is easy to read, while the sidebar, tabs
and status bar stay dark and out of the way.

## What it looks like

- **Grayscale syntax** — most of your code is written in shades of gray, so
  nothing fights for your attention.
- **Subtle colors for important stuff** — only what really matters gets a
  touch of color: strings, types, errors and warnings. Just enough to spot
  them at a glance.
- **Easy on the eyes** — no neon, no rainbow. Low saturation colors that let you
  read code for hours, all of them at WCAG AA contrast or better.

## Install

Search for **bnw-colors** in the Extensions view, then pick
**black and white colors** in the theme list (`Ctrl+K Ctrl+T`).
